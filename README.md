# سازنده دعوتنامه دیجیتال نمایشگاه

یک ویزارد چندمرحله‌ای برای ساخت دعوتنامه اختصاصی هر شرکت برای هر نمایشگاه، با همان قالب دعوتنامه بهان‌سار.
در پایان، دعوتنامه با یک لینک اختصاصی (`/i/<آدرس>`) و کد QR در دسترس قرار می‌گیرد.

## مسیرها

| مسیر | توضیح |
|---|---|
| `/` | صفحه اصلی: ساخت دعوتنامه جدید، فهرست دعوتنامه‌های این مرورگر، ورود مدیر |
| `/builder` | ویزارد ساخت دعوتنامه جدید (پیش‌نویس به‌طور خودکار در مرورگر ذخیره می‌شود) |
| `/builder/<slug>#<token>` | ویرایش دعوتنامه با «لینک ویرایش» خصوصی |
| `/i/<slug>` | دعوتنامه عمومی برای مهمانان (با پیش‌نمایش لینک در تلگرام/واتس‌اپ) |

## مراحل ویزارد

1. **اطلاعات پایه** – نام شرکت، نام نمایشگاه، آدرس لینک (با بررسی آزاد بودن)
2. **برند و ظاهر** – لوگوی افقی، نشان مربعی، لوگوی نمایشگاه، ترکیب رنگ آماده یا دلخواه، ۹ فونت فارسی یا فونت اختصاصی
3. **ویدئو و موزیک** – ویدئوی آماده/دلخواه، تصویر پیش‌بارگذاری، میزان وضوح، موزیک آماده/دلخواه و بلندی صدا
4. **متن‌ها** – خوش‌آمد، متن نامه (با `{company}` و `{event}`)، شعار، متن دکمه‌ها، متن اشتراک‌گذاری، امضای پایین صفحه
5. **زمان و مکان** – تاریخ میلادی برای تقویم + تبدیل خودکار به متن شمسی، ساعت (وقت تهران)، محل، لینک مسیریابی، غرفه، نقشه تعاملی غرفه
6. **انتشار** – بررسی نهایی، لینک اختصاصی، کد QR قابل دانلود، لینک ویرایش

در تمام مراحل، پیش‌نمایش زنده‌ی دعوتنامه داخل قاب گوشی نمایش داده می‌شود.

## اجرا

```bash
npm install
npm run dev          # http://localhost:3000  (Express + Vite)
```

```bash
npm run build        # ساخت فرانت‌اند (dist/) و سرور (dist-server/)
npm start            # اجرای نسخه نهایی
```

## تنظیمات (`.env`)

| متغیر | توضیح |
|---|---|
| `PORT` | پورت سرور (پیش‌فرض ۳۰۰۰) |
| `ADMIN_PASSWORD` | اگر تنظیم شود، ساخت دعوتنامه و بارگذاری فایل فقط با این رمز ممکن است و مدیر فهرست همه دعوتنامه‌ها را می‌بیند. **در محیط واقعی حتماً تنظیم شود.** |
| `DATA_DIR` | محل ذخیره دعوتنامه‌ها (JSON) و فایل‌های بارگذاری‌شده (پیش‌فرض `./data`) – از این پوشه نسخه پشتیبان بگیرید |

در اولین اجرا، دعوتنامه نمونه‌ی بهان‌سار با آدرس `/i/behansar` ساخته می‌شود و لینک ویرایش آن در لاگ سرور چاپ می‌شود.

## ساختار کد

```
server/index.ts                 API، ذخیره‌سازی، بارگذاری فایل، تزریق متاتگ‌های پیش‌نمایش لینک
src/shared/invitation.ts        مدل داده، مقادیر پیش‌فرض، فونت‌ها/پالت‌ها، اعتبارسنجی (مشترک سرور و کلاینت)
src/shared/calendar.ts          تبدیل تاریخ شمسی، لینک گوگل کلندر، فایل ICS
src/invitation/InvitationView.tsx  قالب دعوتنامه (هم برای مهمان و هم پیش‌نمایش ویزارد)
src/pages/                      صفحه اصلی، ویزارد، نمایش دعوتنامه
src/builder/                    مراحل و اجزای فرم ویزارد
```

## امنیت

- لینک‌های واردشده فقط با `http(s)` پذیرفته می‌شوند و فایل‌های رسانه فقط از سرور خودمان.
- فایل‌های بارگذاری‌شده با `Content-Security-Policy: sandbox` سرو می‌شوند (حتی SVG حاوی اسکریپت اجرا نمی‌شود).
- توکن ویرایش فقط به‌صورت hash ذخیره می‌شود و در بخش `#` آدرس قرار دارد تا در لاگ سرورها ثبت نشود.
